1. إضافة dist/design-preview/index.html وdesign.css وhomepage.js لنموذج الرئيسية. إعادة استخدام catalog.js وصوره التوضيحية.
2. إضافة dist/design-preview/search.html وsearch.css وsearch.js وsearch-fixtures.js لنموذج بحث بواجهة SearchProvider قابلة للاستبدال.

## إعادة الاستخدام والتبعيات
إعادة استخدام بيانات الكتالوج، الصور، JavaScript الأصلي، عناصر form/select/dialog الأصلية ودعم RTL. لا إدخال React أو shadcn أو محرك بحث خارجي: المشروع لا يستخدم React، وإضافة إطار لتغيير الشكل وحده غير مبررة. لا حزم جديدة أو خدمات مدفوعة. Inter وNoto Sans Arabic عبر خدمة Google Fonts؛ لا توزيع ملفات خطوط. مراجعة الترخيص والمصادر موثقة بالتقرير.

## ما يتطلب اعتماداً لاحقاً
تعميم التصميم؛ تفعيل Supabase ومخطط قاعدة البيانات؛ ربط Google؛ إدخال شارات بأدلة حقيقية؛ قواعد الأخضر العددية؛ تخزين مستندات التحقق؛ محرك البحث الإنتاجي ومؤشرات الأداء. لا توجد بيانات إنتاجية يجوز تعديلها الآن.

## الاختبارات المخططة
فلاتر متراكبة، شارات OR وعدم ظهور المنتهية، اختلاف الشحن بين وجهتين، حفظ الاستعلام بالعنوان والرجوع، حالات فارغة، الفرز، RTL/LTR، عروض 360/768/1280/1440، لوحة المفاتيح، عدم تغيّر ملفات المتجر الأصلية. اختبارات النماذج لا تثبت صلاحيات قاعدة بيانات أو OAuth أو أداء إنتاجياً.
