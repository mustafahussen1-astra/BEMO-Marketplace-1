# BEMO Marketplace

The public marketplace runs on Sites with a Supabase database. The static frontend is in `dist`. Hosted database changes are tracked in `supabase/migrations`. The delivery-region draft dated 20261117080809 is local only.

The buyer can group purchases by store, confirm a server quote and follow seller updates. The seller controls acceptance, packing, driver dispatch, arrival and delivery. Customer contact is disclosed on acceptance. The ledger supports manual funding decisions and commission holds. Automatic commission collection is disabled.

The current batch adds private seller registration documents, permanent usernames, manual top-up review and cart quantity controls. Full release checks still include signed-in browser journeys for buyer, seller and reviewer. See the workspace continuity files for deployed version IDs.
